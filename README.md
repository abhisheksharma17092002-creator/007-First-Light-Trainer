## 🧬 Architecture at a Glance

Nightfall is built like a covert cell: small, self-contained units that communicate through a hardened bus.

- **Sentinel Core** — the runtime heartbeat, responsible for hook lifecycle and version pinning to the 2026 build.
- **Module Mesh** — a plugin-ready registry. Each capability is a drop-in unit with its own manifest.
- **Whisper Overlay** — a lightweight, GPU-friendly HUD layer that renders only when summoned.
- **Cipher Bridge** — signing and verification scaffold for module authenticity. No third-party payloads. Ever.
- **Midnight Config** — human-readable configuration with hot-reload support.

The whole suite is intentionally low-footprint — a whisper, not a shout.

## 📚 Frequently Asked Questions

**Does Nightfall touch the network or exfiltrate data?**
No. The suite operates entirely on your local machine. Nothing phones home unless you explicitly enable anonymous usage telemetry, which is off by default.

**Will this conflict with my existing mods?**
In most cases, no. Nightfall hooks at a different layer than texture or model mods. If a conflict appears, the log will name the offending signature so you can resolve it calmly.

**Can I disable modules mid-mission?**
Yes. Whisper Overlay supports hot toggling, including a full silent mode that reverts every effect.

**Is there a lightweight profile?**
Yes — the Steam Deck-adjacent profile loads only Sentinel Core plus two modules for minimal overhead.

**Do updates break my presets?**
Presets are version-tagged and auto-migrated when the schema evolves. If a migration is not possible, the previous preset is kept intact under a `.legacy` name.
